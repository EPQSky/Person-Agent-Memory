# 原始会话记录不进入默认记忆检索

原始会话记录是提炼语义记忆的证据，不是普通检索结果。默认 REST 和 MCP 检索只返回经过模型判断、具有来源引用的语义记忆或正式记忆；原始 capture 和按原文拼接的会话单元只在管理台显式原始会话视图中出现。

模型无法确认内容值得长期保存时，不创建语义记忆。模型或提炼流程失败时，采集仍保持 fail-open，但不得发布正式记忆。管理台的记忆列表和详情以正式记忆为对象，原始会话使用独立入口。

采用这一边界是因为问题、命令和临时计划曾被普通检索当成记忆返回。继续混合召回会让对话噪声冒充长期知识。只保存正式记忆而丢弃原始上下文也被拒绝，因为这会失去证据、审计和重新提炼能力。完整转录摘要替代来源证据同样被拒绝，因为摘要无法证明事实来自用户陈述。
