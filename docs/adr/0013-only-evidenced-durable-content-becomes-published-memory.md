# 只有有证据的长期内容才能成为正式记忆

正式记忆限于决策、约束、偏好、领域事实、可复用经验和外部引用；任务进度、临时计划、一次性输出与未验证推测不晋升。会话采集先由模型判断是否存在可长期保存的内容；模型判断为不 eligible 的会话不创建候选记忆。

默认采用“自动晋升优先、人工审核兜底”的两条路径。明确、稳定、来源可追溯、无冲突、非敏感、非重复、策略允许且模型置信度至少为 0.90 的内容直接自动晋升，并保留完整来源和原子变更审计。低置信度、来源不完整、冲突、敏感、重大影响、重复关系或模型异常的内容才进入人工审核。

用户证据按语义判断，不要求用户必须使用“记住”“确认”或“决定”等固定关键词；但用户消息必须对事实作出明确陈述或选择，不能仅提出问题。Codex 回复不能单独成为事实，模型不能用助手回复扩展用户未确认的对象或范围。
