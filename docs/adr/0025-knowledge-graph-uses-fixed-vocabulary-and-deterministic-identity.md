# 知识图谱使用固定词表与确定性实体身份

知识图谱的实体类型限定为 `project`、`technology`、`component`、`concept`、`person`、`organization`、`constraint` 和 `reference`。关系类型限定为 `part_of`、`uses`、`depends_on`、`implements`、`has_constraint`、`prefers`、`references`、`supersedes` 和 `related_to`。模型不得自由创建类型；无法可靠匹配受控词表时不建立实体或关系。

实体身份由实体类型、规范化名称和明确别名确定。只有类型相同且规范化名称完全一致的实体可以自动合并。模型可以提出规范名和别名，但模糊名称、缩写、跨类型同名和向量相似实体保持独立，等待后续受控治理。

实体和关系只在语义记忆发布为正式记忆后异步生成。抽取输入限于正式记忆正文、来源片段和区域信息，不读取问题、临时计划或未发布内容。抽取失败不影响记忆检索，图谱标记为降级并允许重建。用户可见图谱和图扩展只使用该实体知识图谱；关键词共现边不再作为知识关系展示。图谱不可用时检索降级为直接命中。

自由关系名称、基于向量相似度的自动实体合并和保留两套用户可见图语义均被拒绝。它们会制造同义边、错误合并和不可解释的图结构，长期成本高于受控词表和显式治理。
