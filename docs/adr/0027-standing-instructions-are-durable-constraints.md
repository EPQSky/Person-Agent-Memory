# 长期指令是可发布的约束记忆

用户用祈使句表达、但语义上约束未来工作的规则（如「不用走代理」「以后一律用 pnpm」）属于可发布的正式记忆，类型为 `constraint` 或 `preference`；只对当前一轮有效的指令（如「全部提交」「这次不要提交」）不进入记忆。判定以用户消息中的长期标记为依据（以后、一律、统一、每次、永远、默认、从现在起，或未被「这次/本次/本轮/现在/暂时」限定的裸禁止），并要求 `evidence_snippet` 是该消息的精确片段。模型必须把这类证据改写为独立、陈述式的一般规则而不是复述命令；只有当证据携带长期标记时才允许这种受控改写，且改写后仍需共享同一对象词与同一否定极性。助手推断、工具输出与助手单方面结论仍然不能作为记忆证据，此决策不放宽 ADR-0013 与 ADR-0026 的证据约束。
