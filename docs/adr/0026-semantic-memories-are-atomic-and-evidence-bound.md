# 语义记忆按回合原子提炼并绑定用户证据

一个完整回合提炼为零到多条原子语义记忆。每条记忆只表达一个稳定事实、决策、约束、偏好、经验或引用，并改写成脱离对话仍可理解的完整陈述。问题、临时计划、一次性输出和助手单独推断不生成语义记忆。

每条语义记忆必须携带可定位的用户证据片段、来源事件标识、记忆类型、目标区域和置信度。助手最终回复可以提供上下文，但不能单独证明用户事实。没有用户证据的模型正文不能自动发布。

完整回合在助手最终回复后异步提炼，模型调用不进入 Codex Hook 的请求预算。会话结束或压缩前补跑失败、遗漏或未完成的回合。不采用会话级一次总结，因为多事实摘要无法独立去重、冲突判断、替代、遗忘或绑定图谱证据。
