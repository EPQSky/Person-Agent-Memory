# 模型任务使用确定性优先的配置档案

候选记忆判断和图谱抽取属于结构化事实提取任务，应优先保证重复调用的稳定性。两类任务使用独立的模型任务配置档案：图谱抽取默认输出上限为 `max_tokens=4096`，候选判断默认输出上限为 `max_tokens=2048`。两者默认采用 `temperature=0`、`top_p=1`，不强制发送供应商特有的 `top_k`。嵌入和重排序不使用生成采样参数。

不同任务可以继续使用同一个图谱与候选抽取模型，但参数档案由任务决定，而不是依赖 SiliconFlow 或其他 OpenAI 兼容服务的隐式默认值。供应商不支持某个可选参数时，平台应省略该参数并保持基础请求可用。URL、模型名、凭据文件、超时、并发和重试属于传输配置，不与任务采样参数混用，也不因任务档案改变。
