# 管理台使用 24 小时本地会话

管理台是单用户本地工具。用户首次输入平台 API key 并认证成功后，服务签发固定有效期为 24 小时的管理台会话；浏览器刷新期间不要求再次输入 API key。会话使用 HttpOnly、同源限制的 Cookie 传递，浏览器脚本不保存 API key，也不把 API key 放入 `localStorage` 或 `sessionStorage`。

会话状态保存在用户级平台状态目录中，因此记忆服务重启不会在 24 小时有效期内强制重新登录。用户显式退出、API key 轮换或会话过期会立即要求重新认证。该设计保持单用户本地边界，不引入多用户账号体系或远程登录能力。
