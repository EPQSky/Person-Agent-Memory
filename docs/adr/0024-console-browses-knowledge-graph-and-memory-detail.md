# 管理台以知识图谱和记忆详情作为浏览界面

管理台在选中记忆区域后提供“记忆”“图谱”“原始会话”三个工作区标签，检索框位于区域工作区顶部。搜索结果进入正式记忆列表，并可在图谱工作区定位为查询子图。原始会话使用独立的只读时间线，展示用户消息、助手最终回复和由该会话提炼出的语义记忆链接；首版不提供全量原始文本搜索和重新提炼。

记忆列表默认只显示正式语义记忆，按更新时间倒序，每页 50 条。列表项展示摘要、类型、生命周期、更新时间和来源数量，并支持类型、生命周期和关键词筛选。记忆详情使用当前页详情面板，展示完整正文、区域、证据片段、来源会话、版本、关联实体和关系证据，同时保留更正、遗忘和审计入口。

整库图谱默认最多加载 200 个实体节点和 400 条关系边，优先选择连接度较高、最近更新和被检索选中的实体。用户可以搜索实体、按实体类型筛选并渐进展开邻域。查询子图以直接命中的实体为种子，默认一跳，可展开到两跳；直接命中、查询扩展和背景实体使用不同视觉状态。

知识图谱默认只显示当前有效的实体和关系。用户可显式打开历史视图，以弱化样式显示已替代或已失效的关系；已遗忘记忆支撑的节点和边不显示。知识图谱使用实体作为节点、受控类型的关系作为边，语义记忆作为证据层。无法可靠实体化的事实保留在记忆列表中，不为画图强行创建节点。

图谱是由正式记忆派生、可重建的只读投影，不是第二套知识源。修正知识通过修改或遗忘正式记忆完成，再更新受影响的图；后续可以增加受控的实体合并和边隐藏治理，但不能直接编辑图数据。当前基于共享关键词的 `related` 边只可作为内部临时关联索引，不满足知识图谱语义，也不能作为用户看到的最终图谱。
