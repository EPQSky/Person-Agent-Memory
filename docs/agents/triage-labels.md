# Triage labels

- `needs-triage`: evaluation has not finished.
- `needs-info`: a specific answer or reproduction detail is required.
- `ready-for-agent`: sufficiently defined and delegable.
- `ready-for-human`: defined but requires human judgment or access.
- `wontfix`: already implemented or intentionally rejected.

These labels describe intake readiness. Implementation tickets additionally move through `ready-for-agent`, `in-progress`, and `done`.
