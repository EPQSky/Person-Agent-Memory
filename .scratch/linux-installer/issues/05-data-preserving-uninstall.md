# 05 — 保留数据的安全卸载

**What to build:** 为已安装用户提供不依赖原始 Release 目录的稳定卸载入口。普通卸载应停止并移除受管程序、Codex 插件和用户服务，同时保留平台状态及全部记忆库；显式 `--purge` 才额外删除平台状态，并且任何模式都只能移除安装器拥有的配置，绝不自动删除权威记忆。

**Blocked by:** 03 — 自定义目录与持久安装配置

**Status:** ready-for-agent

- [ ] 安装完成后存在稳定的用户级卸载入口，删除原始源码归档或 Release 下载目录后仍可使用。
- [ ] 普通卸载停止并禁用用户服务，移除服务定义、Personal Agent Memory 用户级命令和全局 Codex 插件。
- [ ] 普通卸载保留默认或自定义平台状态目录、API 密钥、安装配置和全部记忆库，并在摘要中列出保留位置。
- [ ] `--purge` 在完成普通卸载后删除已记录的平台状态和安装元数据，但不删除默认或自定义记忆库根目录及其中内容。
- [ ] 卸载器只移除由本次安装创建且未被共享的 Codex marketplace；安装前已经存在或被其他组件使用的 marketplace 保持不变。
- [ ] 已缺失部分程序、插件或服务时，重复卸载仍能安全收敛，不越界删除其他用户配置。
- [ ] 无法证明某个路径属于平台状态时，卸载器保留该路径并报告，而不是猜测后删除。
- [ ] 普通卸载和 `--purge` 全程不调用 `sudo`、系统包管理器或系统级 systemd。
- [ ] 卸载完成后没有 Personal Agent Memory 后台服务或 Codex Hook 继续运行，同时项目仓库状态与 Git remote 不变。
