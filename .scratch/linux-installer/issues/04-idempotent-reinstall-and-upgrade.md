# 04 — 幂等重装与原地升级

**What to build:** 让用户通过再次运行安装器安全修复当前版本或升级到新版本。流程应有序停止记忆守护进程，收敛程序、Codex 插件和用户服务到目标发行版本，保留安装配置与全部用户数据，再恢复服务并验证真实可用性；任何失败都不能以删除数据作为恢复手段。

**Blocked by:** 03 — 自定义目录与持久安装配置

**Status:** done

- [x] 再次运行相同版本安装器不会生成重复的 Codex 插件、marketplace 或 systemd 服务记录。
- [x] 相同版本重装可以修复缺失的受管安装产物，并在完成后通过认证健康检查。
- [x] 从旧发行版本升级时，用户服务在替换程序、插件或服务定义前被有序停止。
- [x] 升级后 Personal Agent Memory 命令与 Codex 插件均对应目标发行版本，用户服务重新启用并恢复健康。
- [x] 默认和自定义安装在升级后都保持原有平台状态目录与记忆库根目录。
- [x] 升级前后的 API 密钥、记忆库注册表、项目绑定、候选记忆、审计数据和权威记忆保持不变。
- [x] 升级完成后真实 Codex Hook 可以继续连接服务，不要求用户重新配置各项目。
- [x] 在程序更新、插件更新或服务启动阶段注入失败时，安装器返回非零状态、说明失败阶段和诊断命令，并保留平台状态及全部记忆库。
- [x] 重装与升级均不调用 `sudo`，也不修改项目仓库状态或 Git remote。
