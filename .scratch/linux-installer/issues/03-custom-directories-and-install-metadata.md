# 03 — 自定义目录与持久安装配置

**What to build:** 允许用户在安装时覆盖平台状态目录和记忆库根目录，并把规范化、经过验证的选择持久用于服务运行、重复安装、升级和卸载。安装配置必须清楚区分可由平台清理的状态与永远不得自动删除的记忆库。

**Blocked by:** 01 — 受支持环境的一键安装

**Status:** done

- [x] 用户可以分别覆盖平台状态目录和记忆库根目录，也可以只覆盖其中一项并保留另一项默认值。
- [x] 路径参数会进行用户目录展开、绝对化和可用性检查；无效、冲突或不可用路径在服务启动前被拒绝并得到明确说明。
- [x] 自定义目录不存在时会在普通用户权限内安全创建，无法创建时安装失败且不报告部分成功。
- [x] 用户级 systemd 服务使用最终确认的自定义目录，服务重启后仍保持相同配置。
- [x] 安装选择被持久记录，使重复安装、升级和卸载无需从运行进程猜测目录。
- [x] 安装元数据不得存入任何记忆库，也不得包含 API 密钥正文。
- [x] 默认与自定义记忆库根目录均被标记为用户内容，任何清理流程都不得把它们当作平台状态删除。
- [x] 使用自定义目录安装后，认证健康检查和真实 Codex Hook 与默认安装具有相同行为。
