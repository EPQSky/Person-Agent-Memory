# 05 — 实体知识图谱基础与记忆关联

**What to build:** 正式语义记忆发布后，系统异步抽取固定类型的实体和关系。用户打开记忆详情时，可以看到关联实体、关系证据和一个可点击的局部图。实体身份稳定，重复执行不会重复建图，没有正式记忆证据的节点或边不会出现。

**Blocked by:** 01 — 管理台正式记忆列表与详情；03 — 回合级原子语义提炼。

**Status:** ready-for-agent

- [ ] 只从正式语义记忆正文、已保存证据和区域信息抽取实体与关系。
- [ ] 实体类型限定为 `project`、`technology`、`component`、`concept`、`person`、`organization`、`constraint` 和 `reference`。
- [ ] 关系类型限定为 `part_of`、`uses`、`depends_on`、`implements`、`has_constraint`、`prefers`、`references`、`supersedes` 和 `related_to`。
- [ ] 词表外类型、悬空关系、无证据关系和敏感关系被拒绝。
- [ ] 实体身份由实体类型、规范化名称和明确别名确定，类型不同的同名对象保持独立。
- [ ] 不依据向量相似度、模糊拼写或模型自行判断自动合并实体。
- [ ] 同一正式记忆内容重复发布、重建或服务重启后，图谱节点和边保持幂等。
- [ ] 用户可以在记忆详情看到关联实体、关系类型、关系证据和局部图。
- [ ] 点击实体或关系可以查看支撑它的正式记忆与来源。
- [ ] 无法可靠实体化的记忆仍保留在记忆列表，不强行创建图谱节点。
- [ ] 图谱是只读派生投影，不提供直接编辑图数据的入口。
- [ ] 服务级测试覆盖固定词表、实体身份、跨类型同名、幂等、悬空关系、无证据关系、敏感关系和重启恢复。
- [ ] 浏览器验收覆盖从正式记忆详情进入关联实体和局部图的路径。
