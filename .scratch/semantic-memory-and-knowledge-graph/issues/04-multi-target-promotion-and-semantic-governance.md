# 04 — 多目标晋升与语义治理

**What to build:** 语义提炼结果按稳定内容进入正确记忆区域。个人偏好和长期事实可以进入用户记忆，可泛化知识可以进入匹配专题，项目事实留在项目区域。重复内容只增补来源，冲突和敏感内容不自动覆盖当前有效记忆。

**Blocked by:** 03 — 回合级原子语义提炼。

**Status:** ready-for-agent

- [ ] 稳定个人事实可自动晋升到用户记忆区域。
- [ ] 可泛化知识可晋升到已存在且匹配的专题记忆区域。
- [ ] 项目特定事实留在当前项目记忆区域，不污染用户或专题区域。
- [ ] 无法确定目标的内容保留在来源区域，不创建新区域。
- [ ] 等价语义记忆只增加来源引用和证据，不复制正文或创建重复列表项。
- [ ] 冲突内容不自动覆盖当前有效记忆，并留下可审计的冲突结果。
- [ ] 敏感内容不自动发布，不进入普通检索，也不进入图谱证据。
- [ ] 晋升后的记忆保留原始回合、证据片段、来源区域和版本链。
- [ ] 记忆详情显示晋升目标、来源区域和证据依据。
- [ ] 重复执行晋升和提炼保持幂等，不重复写审计或来源。
- [ ] 服务级测试覆盖用户晋升、专题晋升、项目保留、重复、冲突、敏感、幂等和审计。
- [ ] 浏览器验收覆盖项目事实留在项目区域、个人偏好出现在用户区域的可见结果。
