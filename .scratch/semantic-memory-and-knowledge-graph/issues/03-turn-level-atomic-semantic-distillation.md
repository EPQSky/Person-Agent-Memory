# 03 — 回合级原子语义提炼

**What to build:** 一个完整回合在助手最终回复后异步生成零到多条原子语义记忆。用户问普通问题时不发布记忆；用户明确陈述偏好、约束或事实时，生成带用户原文证据的正式记忆。提炼失败或遗漏会在会话结束或压缩前补跑，Codex 回合不被模型调用阻塞。

**Blocked by:** 01 — 管理台正式记忆列表与详情；02 — 原始会话与默认召回边界。

**Status:** ready-for-agent

- [ ] 只有同一回合的用户消息和助手最终回复都到达后，回合才进入可提炼状态。
- [ ] 助手最终回复成功后异步触发提炼，Hook 请求预算内不等待模型完成。
- [ ] 模型返回零条结果时不创建正式记忆。
- [ ] 模型返回多条结果时，每条记忆只表达一个可独立修正的原子主张。
- [ ] 语义记忆正文自包含，不依赖“上面”“刚才”等对话指代。
- [ ] 每条结果包含允许的记忆类型、置信度、区域提示、用户证据事件标识和用户原文证据片段。
- [ ] 证据片段必须能在对应用户事件中确定性定位；缺失或无法定位时不发布该条记忆。
- [ ] 助手回复不能单独成为用户事实证据。
- [ ] 问题、临时计划、一次性输出、隐藏推理和工具原始输出不生成正式记忆。
- [ ] 通过证据、类型、敏感检查、置信度至少 `0.90` 和冲突检查的结果进入正式记忆。
- [ ] 模型异常、无效 JSON、无效证据和低置信度结果不发布正式记忆，并记录可诊断的跳过或失败状态。
- [ ] 重复处理同一回合幂等，不因 Hook 重放、后台重试或服务重启产生重复记忆。
- [ ] 会话结束和压缩事件能够补跑失败、遗漏或未合并完成的提炼轮次。
- [ ] 新语义记忆立即出现在正式记忆列表、详情和默认检索中，并可从原始会话回合反查。
- [ ] 服务级测试覆盖零条、一条、多条、问题、助手单独内容、无效证据、模型失败、幂等和重启恢复。
- [ ] 浏览器验收覆盖“提问不生成记忆，明确偏好生成带来源记忆”的用户路径。
