# 01 — 管理台正式记忆列表与详情

**What to build:** 用户选中记忆区域后，可以在管理台看到可点击的正式记忆列表，并按类型、生命周期和关键词筛选。点击一条记忆后，用户在详情面板看到正文、来源、版本、生命周期和审计信息，并能完成现有更正或遗忘操作。

**Blocked by:** 无，可立即开始。

**Status:** ready-for-agent

- [ ] 管理台默认显示正式记忆列表，不把原始 capture 或旧原样拼接单元混入列表。
- [ ] 列表按更新时间倒序，每页 50 条，并支持游标分页。
- [ ] 列表项显示摘要、记忆类型、生命周期、更新时间和来源数量。
- [ ] 用户可以按关键词、记忆类型和生命周期筛选列表。
- [ ] 点击列表项打开当前页详情面板，不要求用户直接编辑不透明的记忆路径。
- [ ] 详情展示完整正文、区域、类型、证据与来源、版本、生命周期和审计入口。
- [ ] 详情保留现有更正、遗忘和审计操作，操作后列表和详情状态保持同步。
- [ ] 空列表、加载失败、认证失效和分页结束都有明确用户提示。
- [ ] 浏览器验收覆盖登录、选择区域、看到列表、点击详情和完成一次治理操作。
