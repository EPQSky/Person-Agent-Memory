# 07 — 检索查询子图

**What to build:** 用户在区域工作区执行检索后，可以在整库知识图谱中定位直接命中的实体，并查看一跳关系。用户可显式展开到两跳；直接命中、查询扩展和背景实体视觉区分，记忆列表和查询子图能够互相定位。

**Blocked by:** 06 — 整库有界图谱、历史与降级。

**Status:** ready-for-agent

- [ ] 检索结果中的正式记忆可以映射到知识图谱实体。
- [ ] 查询子图以直接命中的实体为种子，默认显示一跳关系。
- [ ] 用户可以把查询子图显式展开到两跳，不提供超过两跳的浏览。
- [ ] 直接命中、查询扩展和背景实体使用不同视觉状态。
- [ ] 点击列表结果可以定位对应实体和关系，点击图中实体可以定位相关记忆列表项。
- [ ] 查询子图仍受节点和边上限约束，并显示截断或降级状态。
- [ ] 原始会话记录和旧关键词共现边不出现在查询子图中。
- [ ] 没有可映射实体时，记忆列表仍可用，并明确提示无法定位图谱。
- [ ] 图谱不可用时，检索结果和记忆详情继续可用，并显示降级原因。
- [ ] 服务级测试覆盖一跳、两跳、视觉分类数据、上限、无实体、降级和列表图谱联动契约。
- [ ] 浏览器验收覆盖“检索结果 → 查询子图 → 展开两跳 → 返回记忆详情”的完整路径。
