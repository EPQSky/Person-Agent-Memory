# 06 — 整库有界图谱、历史与降级

**What to build:** 用户在“图谱”标签中浏览当前区域的知识结构。默认图有明确节点和边上限，支持实体搜索、类型筛选和渐进展开。默认只显示有效内容，用户可以打开历史视图查看失效关系，遗忘内容不会出现；图服务异常时，用户仍能使用直接记忆检索。

**Blocked by:** 05 — 实体知识图谱基础与记忆关联。

**Status:** done

- [x] 管理台提供“图谱”标签，并与“记忆”“原始会话”标签清晰切换。
- [x] 整库图默认最多返回 200 个实体节点和 400 条关系边。
- [x] 默认节点优先选择连接度高、最近更新和被检索选中的实体。
- [x] 用户可以搜索实体、按实体类型筛选并渐进展开邻域。
- [x] 默认图只显示当前有效实体和关系。
- [x] 历史视图弱化显示已替代或已失效的关系。
- [x] 已遗忘记忆支撑的节点和边不显示在默认图或历史图。
- [x] 图谱状态显示节点数、边数、已投影记忆数、待处理数、错误和更新时间。
- [x] 用户可以触发幂等重建，重建失败不破坏现有可读数据。
- [x] 图索引不可用时，正式记忆直接检索仍成功，并报告图谱降级原因。
- [x] 不提供直接编辑、合并或删除图谱节点与边的入口。
- [x] 服务级测试覆盖上限、排序、筛选、历史、遗忘隐藏、重建、降级和重启持久化。
- [x] 浏览器验收覆盖整库图加载、类型筛选、实体搜索、历史切换和图谱降级提示。
