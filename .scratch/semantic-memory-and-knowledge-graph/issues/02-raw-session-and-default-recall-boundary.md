# 02 — 原始会话与默认召回边界

**What to build:** 用户提出的普通问题不再出现在普通记忆检索中，但仍可在管理台“原始会话”标签中按会话和回合查看。原始会话记录与正式记忆使用不同入口，旧 capture 和原样拼接单元不再冒充长期知识。

**Blocked by:** 01 — 管理台正式记忆列表与详情。

**Status:** ready-for-agent

- [ ] 默认 REST、MCP 和 Codex 检索排除原始 capture 与旧原样拼接的 evolved 单元。
- [ ] 搜索“项目”不会返回“帮我分析下当前项目”这类未被提炼的用户提问。
- [ ] 原始会话接口支持按区域、会话和回合读取用户消息、助手最终回复和接收时间。
- [ ] 管理台提供“原始会话”标签，按会话时间线只读展示回合和事件。
- [ ] 原始会话视图显示回合待完成、待提炼、完成或失败状态。
- [ ] 原始会话首版不提供全量文本搜索和重新提炼操作。
- [ ] 未完成回合、空会话和读取失败都有明确提示。
- [ ] Hook 采集、spool 重放和 fail-open 行为不因新视图改变。
- [ ] 浏览器验收覆盖“正式记忆看不到提问，但原始会话能看到提问”的完整路径。
