# 03 — 显式绑定项目与解析 Codex 工作目录

**What to build:** 让用户显式绑定项目根目录和项目记忆库，并让平台根据 Codex 会话工作目录可靠解析当前项目；未绑定项目不猜测、不回退，worktree 只有在用户配置后才继承主项目绑定。

**Blocked by:** 02 — 注册和管理记忆库

**Status:** ready-for-agent

- [ ] 用户可以从 Web 将一个规范项目根目录绑定到一个项目记忆库，并查看、修改或解除绑定。
- [ ] 绑定用户记忆库作为项目默认库被拒绝，且不会产生部分写入的注册状态。
- [ ] 给定项目根目录内的 Codex `cwd`，REST/MCP 解析得到唯一项目绑定和稳定记忆库标识。
- [ ] 未绑定目录返回明确的未绑定状态，不按 basename 猜测，也不回退到用户记忆库或最近使用的项目库。
- [ ] 同名但路径不同的项目保持隔离，嵌套项目按最具体的显式绑定解析。
- [ ] worktree 默认不继承绑定；用户显式关联主项目后，其工作目录解析到同一项目记忆库。
- [ ] 项目目录移动或消失时绑定进入可诊断状态，不自动重绑到同名目录。
- [ ] Docker 验收覆盖正常绑定、未绑定、同名项目、嵌套项目、显式 worktree 继承和解除绑定。
