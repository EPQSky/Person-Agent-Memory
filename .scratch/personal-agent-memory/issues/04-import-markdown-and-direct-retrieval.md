# 04 — 导入 Markdown 并完成直接检索

**What to build:** 让已绑定项目的现有 Markdown 在不改写原文的情况下被扫描、结构化切片并建立全文索引，使用户可以通过 Web、REST 与 MCP 从当前项目记忆库获得带来源和版本的直接命中。

**Blocked by:** 03 — 显式绑定项目与解析 Codex 工作目录

**Status:** ready-for-agent

- [ ] 注册已有 Markdown 目录后，平台扫描普通 `.md` 文档，并默认排除版本控制、依赖、构建、缓存和平台运行状态目录。
- [ ] 用户可配置 ignore 规则；越出记忆库根目录的符号链接不被跟随或索引。
- [ ] 文档按标题层级和段落形成稳定片段，围栏代码块保持完整，不因切片产生无法配对的围栏。
- [ ] 初始全文索引完成后，Web、REST 与 MCP 可以按关键词查询当前项目记忆库，并返回内容、库标识、路径、标题或行位置及来源版本。
- [ ] 查询默认范围仅为当前项目记忆库；未绑定项目得到明确结果，不能看到用户库或其他项目库内容。
- [ ] 已有 Markdown 不被强制写入 frontmatter；平台 sidecar 保存稳定文档和片段标识。
- [ ] 文件新增、受支持的平台变更和重新扫描可增量更新全文索引，删除的来源不会继续出现在结果中。
- [ ] Docker 验收使用包含中文、英文、标题、重复段落、长段落和代码块的真实目录验证导入与来源定位。
