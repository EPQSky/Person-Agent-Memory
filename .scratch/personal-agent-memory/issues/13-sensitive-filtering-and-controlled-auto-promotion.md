# 13 — 敏感过滤与受控自动晋升

**What to build:** 在会话内容持久化和模型处理前识别秘密与疑似敏感信息，并只让同时满足类型、证据、来源、冲突和策略要求的候选自动晋升为正式记忆。

**Blocked by:** 07 — 向量混合检索与模型降级；12 — Codex 会话采集到候选记忆

**Status:** done

- [x] API Key、访问令牌、密码、私钥及配置的秘密模式在进入持久 Inbox、spool 或模型请求前被检测和清除。
- [x] 明确秘密不进入 Markdown、SQLite 正文、模型请求、Git、向量、Graph 或普通日志。
- [x] 无法确定的敏感内容进入隔离状态，默认不可搜索、不可自动晋升，并可由用户查看受控摘要后处置。
- [x] 自动晋升仅允许决策、约束、偏好、领域事实、可复用经验和外部引用；任务进度、临时计划、一次性输出和未验证推测被拒绝。
- [x] 助手回复单独不能证明用户或项目事实；候选必须具有用户确认或可验证项目证据。
- [x] 自动晋升必须同时通过来源有效性、重复检测、冲突检测、敏感检查和库策略，模型置信度不能绕过任一硬条件。
- [x] 自动晋升通过平台写入协调器创建正式 Markdown 和独立 Git 提交，并标明后台任务与来源会话。
- [x] Docker 验收覆盖常见秘密、分段秘密、误报隔离、无证据助手陈述、合格决定、冲突候选、模型高置信度越权和日志泄漏检查。
