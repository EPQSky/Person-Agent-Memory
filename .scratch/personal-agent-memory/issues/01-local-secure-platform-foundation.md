# 01 — 可运行的本地安全平台骨架

**What to build:** 建立可原生启动的单用户本地记忆守护进程与浏览器管理界面，使用户和兼容客户端可以通过受 API Key 保护的 Web、REST 与 MCP 健康接口确认服务可用，并为后续纵向能力提供真实 SQLite、Docker 假模型和自动化验收基线。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] Linux 用户可以通过项目规定的 `uv` 或 Python 包工作流启动单一守护进程，并打开管理界面查看服务状态。
- [ ] Web、REST 与 MCP 默认只监听 loopback；从非 loopback 地址启动必须明确失败，而不是静默扩大暴露范围。
- [ ] 首次启动生成随机 API Key，并以受限文件权限保存；未认证或错误密钥访问受保护接口时得到一致的拒绝结果。
- [ ] 用户可以轮换 API Key，旧密钥立即失效，日志和界面仅显示密钥指纹而不泄露明文。
- [ ] SQLite 持久化和后台任务执行框架可运行，并能在守护进程重启后恢复基础服务状态。
- [ ] Docker 验收环境能启动真实守护进程、真实 SQLite 和确定性 OpenAI-compatible 假模型服务，并通过公开接口完成健康检查。
- [ ] 自动化验证覆盖缺失配置、端口占用、错误密钥、损坏状态库和干净重启，不依赖外部付费模型。
- [ ] 项目许可证明确为 Apache-2.0，且依赖和分发元数据与该许可一致。
