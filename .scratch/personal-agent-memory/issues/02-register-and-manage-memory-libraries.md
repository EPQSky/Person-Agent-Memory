# 02 — 注册和管理记忆库

**What to build:** 让用户从管理平台注册、查看和管理用户记忆库或项目记忆库，自动创建不存在的目录，并通过中央记忆库注册表向 Web、REST 与 MCP 暴露稳定标识、规范路径和同步状态。

**Blocked by:** 01 — 可运行的本地安全平台骨架

**Status:** done

- [x] 用户可以注册一个不存在的本地目录，平台创建目录并返回稳定且不会因重启改变的记忆库标识。
- [x] 用户可以注册已有目录，并明确选择用户记忆库或项目记忆库类型，不修改其中已有 Markdown 内容。
- [x] 同一规范路径不能被重复注册为两个不同记忆库；符号链接、相对路径和大小写差异按平台规则得到一致结果。
- [x] 记忆库路径必须处于允许的本地文件系统边界内，越界符号链接和不可访问路径被拒绝并给出可操作原因。
- [x] Web、REST 与 MCP 可以列出记忆库的稳定标识、类型、规范路径、可用性和同步状态，但不暴露 API Key 或模型凭据。
- [x] 目录临时消失、权限被撤销或重新出现时，平台更新健康状态而不删除注册信息或猜测替代路径。
- [x] 守护进程重启后中央注册表完整恢复，多记忆库之间的类型、标识和状态保持隔离。
- [x] Docker 验收覆盖新目录创建、已有目录采用、重复注册、路径越界、不可写目录和重启恢复。
