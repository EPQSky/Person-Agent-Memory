# 11 — Codex 全局插件的记忆召回

**What to build:** 提供可全局安装的 Codex 插件和 Hooks，使每轮用户提示提交时根据会话工作目录解析当前项目并注入受预算约束的项目记忆，同时保证未绑定、超时和服务故障不会阻塞 Codex。

**Blocked by:** 03 — 显式绑定项目与解析 Codex 工作目录；09 — 10K 记忆上下文包与完整 MCP 检索契约

**Status:** ready-for-agent

- [ ] 插件可以全局安装并配置 Hooks 与 MCP 连接，不需要向每个项目写入配置文件。
- [ ] UserPromptSubmit Hook 使用事件 `cwd` 和 API Key 请求当前项目记忆，成功时将明确标界的不可信记忆上下文输出给 Codex。
- [ ] 注入内容只来自解析出的项目记忆库，除非用户通过显式 MCP 工具查询用户库。
- [ ] 未绑定项目、无相关结果或服务返回降级空结果时 Hook 正常退出且不注入其他记忆库内容。
- [ ] Hook 使用短超时和有限输出；守护进程不可用、认证失败、响应畸形或超时时仍以成功退出，不阻塞用户提示。
- [ ] 插件不会把 API Key、原始服务错误或内部路径泄露到注入上下文。
- [ ] PreCompact 可以重新请求受预算记忆以帮助压缩，但不能成为会话采集正确性的唯一时机。
- [ ] Docker 验收执行真实 Node.js Hook stdin/stdout，覆盖绑定项目、同名项目、未绑定、错误密钥、超时、服务停止和 10K 上限。
