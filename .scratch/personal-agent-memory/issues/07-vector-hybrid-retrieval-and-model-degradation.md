# 07 — 向量混合检索与模型降级

**What to build:** 在直接 Markdown 检索中加入可配置的向量语义召回和可选重排，使精确标识与语义相关内容都能被找到，并在模型组件异常时自动退回可追溯的全文结果。

**Blocked by:** 04 — 导入 Markdown 并完成直接检索

**Status:** ready-for-agent

- [ ] 用户可以独立配置 OpenAI-compatible Embedding 与 Reranker 服务，凭据不进入记忆库、Git 历史或普通日志。
- [ ] 平台为 Markdown 片段建立可重建的向量索引，并将全文与向量候选统一去重和排序。
- [ ] 精确项目标识、命令和错误文本可通过全文检索命中，语义改写查询可通过向量检索命中相关片段。
- [ ] Reranker 启用时对合并候选进行重排；其失败、超时或畸形响应保留重排前顺序并标记降级。
- [ ] Embedding 服务不可用时查询继续通过 FTS 返回来源完整的结果，不将模型异常作为整体检索失败。
- [ ] 文档版本变化后旧向量不可再被返回，后台重建完成前可使用最新全文结果。
- [ ] 模型请求具有明确超时、并发上限和受控重试，不会无限阻塞后台队列或查询。
- [ ] Docker 验收使用确定性假模型覆盖语义召回、混合排序、重复片段、超时、错误响应和完全离线降级。
