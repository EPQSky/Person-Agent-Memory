# 01 — 管理界面现代化与简体中文化

**What to build:** 将现有管理界面一次性改造为参考 Semi Design 中后台语言的简体中文工作台。认证后提供侧边导航、顶部状态栏、概览和分区工作区，完整保留记忆库、项目绑定、检索、候选记忆治理、敏感隔离、权威记忆文档编辑、带外变更、本地历史、遗忘恢复和隐私设置能力；同时补齐加载、空状态、操作反馈、危险确认及桌面优先的响应式布局，不改变后端 API 或记忆领域行为。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 登录页使用“个人智能体记忆”作为主名称并保留 `Personal Agent Memory` 副标识，认证说明、错误反馈和无障碍文本均为简体中文。
- [ ] API 密钥仍只保留在当前页面运行内存中，不预置于页面、不进入 URL，也不写入 `localStorage` 或其他持久化浏览器存储。
- [ ] 认证成功后默认进入概览，并通过侧边导航、顶部状态栏和主工作区访问全部既有管理能力。
- [ ] 一级导航包含概览、记忆检索、候选审核和文档管理；记忆库、项目绑定、敏感隔离、历史恢复和隐私设置归入“管理与治理”分组。
- [ ] 概览使用现有接口展示服务状态、数据库和后台任务状态、记忆库信息以及可获取的候选、敏感隔离和索引异常摘要，并提供高频操作入口。
- [ ] 所有面向用户的标题、字段标签、选项、按钮、状态说明、空状态、加载提示、成功消息、错误上下文、确认内容、工具提示和无障碍标签均使用简体中文。
- [ ] 路径、记忆库和项目标识、提交哈希、来源版本、用户 Markdown、API 字段和值等技术数据保持原样；已知枚举状态使用中文显示标签但不改变底层值。
- [ ] 记忆库注册、项目绑定和 worktree 关联流程可完整使用，状态使用易扫描的中文徽标表达，解绑和移除关联前需要确认。
- [ ] 记忆检索支持加载、未绑定、无结果、降级、失败和正常结果状态，并保留路径、行号、分类、图跳数和来源版本等来源信息。
- [ ] 候选记忆继续支持筛选、查看来源与冲突、编辑、置顶、批准、拒绝及全部既有冲突裁决方式。
- [ ] 敏感隔离继续支持分页、刷新、确认和丢弃，且与普通候选记忆在导航和视觉语义上明确分离。
- [ ] 权威记忆文档继续支持文档导航、Markdown 源文、渲染预览、差异预览、保存前检查和来源版本并发保护。
- [ ] 带外变更继续支持基准、平台和外部内容比较，以及既有导入或恢复流程；所需信息不完整时提交动作保持禁用。
- [ ] 本地历史和遗忘恢复继续展示可核查的路径、提交与差异信息，恢复仍通过新的记忆变更事务完成。
- [ ] 隐私设置继续支持保留策略、清理预览、立即清理、诊断清除和可恢复内容操作，并以可读中文呈现影响。
- [ ] 所有异步操作表达处理中、成功和失败状态，并防止相同操作在等待响应期间被重复提交。
- [ ] 危险操作使用统一中文确认对话框；遗忘及可能影响权威记忆和派生数据的高风险操作要求明确的强化确认。
- [ ] 视觉系统采用白灰基底、字节蓝主交互色、青绿色成功色、橙色提醒和红色危险色，控件圆角不超过 8px，不使用外部 CDN、营销式英雄区、装饰性渐变或光斑。
- [ ] 页面在桌面宽度下保持紧凑、稳定且可扫描；窄屏下导航可收起、主从布局转为单栏、表格可滚动，文本和操作不重叠或被裁切。
- [ ] 动效保持克制并尊重 `prefers-reduced-motion`，键盘焦点清晰可见，图标按钮具有简体中文工具提示和可访问名称。
- [ ] 现有管理页面契约测试同步更新为稳定的简体中文断言，同时继续验证页面不泄露 API 密钥、密钥指纹或平台目录。
