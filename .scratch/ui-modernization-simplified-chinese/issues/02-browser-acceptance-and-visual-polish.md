# 02 — 真实浏览器验收与视觉收尾

**What to build:** 在完成中文管理工作台后，从真实用户视角运行本地服务并使用现有 Selenium 浏览器接缝验收主要工作流、安全边界和响应式布局。通过桌面与窄屏截图检查并修复遗漏英文、交互状态、可访问性、文本溢出、遮挡和视觉不一致，使最终界面达到可交付质量。

**Blocked by:** 01 — 管理界面现代化与简体中文化

**Status:** ready-for-agent

- [ ] Selenium 可以使用真实登录控件完成认证，并验证失败提示和认证后的默认概览均为简体中文。
- [ ] 浏览器可以通过新导航进入所有既有管理功能，不需要访问隐藏入口或操作开发者控制台。
- [ ] 至少验证一条记忆检索流程，覆盖加载状态、结果来源信息以及无结果、未绑定或降级状态中的代表性反馈。
- [ ] 至少验证一条候选记忆治理流程，确认查看详情、填写治理信息和执行批准或拒绝仍产生正确的外部结果。
- [ ] 至少验证一条权威记忆文档流程，确认选择文档、编辑、预览差异和保存仍遵守现有来源版本与平台修改约束。
- [ ] 至少验证一条带外变更或历史恢复流程，确认比较、确认和恢复行为未因界面重组发生回归。
- [ ] 至少验证一项危险操作：取消确认时不得发送修改请求，完成规定确认后才执行操作并显示中文结果。
- [ ] 浏览器验收确认异步操作期间相关按钮禁用，连续点击不会产生重复请求或重复记忆变更事务。
- [ ] 浏览器验收确认 API 密钥未进入页面源码、URL、`localStorage` 或其他持久化浏览器存储。
- [ ] 使用代表性桌面视口截图检查导航、顶部状态、概览、表格、主从工作区、编辑器和对话框的视觉层级与一致性。
- [ ] 使用代表性窄屏视口截图检查导航收起、单栏转换、表格滚动、长路径、中文长文案及底部操作均可查看和操作。
- [ ] 截图和浏览器检查中不得存在内容重叠、非预期裁切、页面级非预期横向溢出、空白工作区或不可达操作。
- [ ] 全界面搜索并修复面向用户的遗漏英文；技术数据、英文副标识和用户内容不计为遗漏。
- [ ] 键盘可以按合理顺序访问导航、表单、标签页、列表详情和确认对话框，焦点可见且关闭对话框后返回合理位置。
- [ ] 图标按钮、动态反馈和状态具备准确的简体中文可访问名称，减少动态效果偏好下不执行非必要动效。
- [ ] 相关 FastAPI 页面测试、前端辅助逻辑测试及 Selenium/Docker 浏览器验收全部通过。
- [ ] 最终检查不使用逐像素快照作为通过条件，而以用户可观察行为、无布局缺陷和整体视觉一致性为准。
