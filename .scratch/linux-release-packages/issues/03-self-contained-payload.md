# 03 — 自包含 payload 构建

**What to build:** 在固定基础镜像的容器内，从锁文件构建出自包含 payload：内置受支持的 CPython 运行时、虚拟环境、全部依赖与 Codex 插件。构建完成后的 payload 在无网络、无 `uv`、不依赖系统 Python 的干净容器中启动守护进程并通过认证健康检查。构建过程不修改工作树。

**Blocked by:** 01 — 用户初始化核心. 与 02 可并行。

**Status:** done

- [x] payload 内运行时版本满足项目要求
- [x] 干净容器内离线启动守护进程并通过认证健康检查
- [x] 目标容器没有可用系统 Python 与 `uv` 时仍可运行
- [x] 构建脚本把运行时来源、安装前缀与服务注册方式参数化，为后续平台复用留出接口
