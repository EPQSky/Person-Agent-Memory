# 01 — 用户初始化核心

**What to build:** 用户在自己账户下执行 `personal-agent-memory setup`，命令完成前置依赖检查与版本一致性校验，创建受保护的状态目录、记忆库根目录与 API 密钥，写入以 `package` 方式标记的安装元数据；任一类冲突存在时以非零状态拒绝且不写入任何状态；重复执行保持幂等。本票不注册用户级服务与 Codex 插件。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 缺少 Node.js、Codex CLI 或 Git 时报告具体缺失项与修复指引，并在写入任何状态之前失败
- [ ] 包版本、插件清单版本与项目版本不一致时拒绝继续
- [ ] 状态目录、记忆库根目录与 API 密钥按既有权限语义创建，密钥不可被其他用户读取
- [ ] 安装元数据区分 `script` 与 `package` 方式，且包方式不写脚本安装专属的卸载器所有权字段
- [ ] 冲突按安装方式区分：同方式元数据是幂等收敛而非冲突；异方式元数据（`script` 与 `package` 互见）拒绝
- [ ] 其余三类冲突拒绝并给出可执行指引：PATH 上被遮蔽的同名命令、目标端口被占用、非本安装拥有的用户级服务定义
- [ ] 重跑收敛到当前状态，不重置 API 密钥，不重复写元数据
- [ ] 命令行行为测试覆盖以上场景，使用临时 HOME 与 XDG 目录并伪造外部命令
