# 04 — deb 与 rpm 发行包

**What to build:** 用一份打包配置产出 `.deb` 与 `.rpm`，把 payload 安装到独立前缀、在系统可执行目录暴露命令包装器、提供文档与许可证；包安装不写用户主目录、不操作用户 systemd。在单个干净容器中完成完整演示：装包 → `setup` → 认证健康检查 → 记忆写入与召回 → 卸载后程序文件清理而用户数据保留。

**Blocked by:** 02 — 用户级服务与 Codex 插件注册；03 — 自包含 payload 构建.

**Status:** done

- [x] 两种包格式来自同一 payload 与同一元数据定义
- [x] 包的安装与卸载脚本不包含任何用户态操作
- [x] 卸载只移除程序文件，保留平台状态、API 密钥与全部记忆库
- [x] 单容器端到端演示通过：安装、初始化、读写记忆、卸载保数据
- [x] 包版本、插件版本与项目版本一致
- [x] 包内文件清单符合发行版布局约定，命令可从 PATH 直接调用
