# 01 — 确定性模型任务配置

**What to build:** 为候选记忆判断和图谱抽取建立确定性优先的模型任务配置，使结构化提取不再依赖供应商默认采样参数，同时保持嵌入、重排序和现有传输配置兼容。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 候选记忆判断和图谱抽取请求显式使用 `temperature=0` 和 `top_p=1`，并设置与任务匹配的有界输出上限。
- [ ] 请求不强制发送供应商特有的 `top_k`；未配置或不支持的可选参数不会破坏 OpenAI 兼容请求。
- [ ] 嵌入和重排序请求不携带生成采样参数。
- [ ] 现有模型 URL、模型名、凭据文件、超时、并发和重试配置继续有效。
- [ ] 候选判断和图谱抽取可以拥有独立的任务配置档案，但默认继续使用现有图谱模型端点。
- [ ] 确定性模型请求契约测试覆盖请求字段、输出上限和嵌入/重排序参数隔离。
- [ ] 中文文档说明模型任务的默认参数和哪些参数不作为通用配置。
