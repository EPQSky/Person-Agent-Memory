# 02 — 自动晋升优先与异常候选治理

**What to build:** 将会话记忆处理调整为“模型判断、自动晋升优先、人工审核兜底”，让明确且低风险的长期内容直接进入正式记忆，只把真正需要治理的例外保留在候选队列。

**Blocked by:** None — can start immediately

**Status:** done

- [x] 模型判断为不适合长期保存的会话不会创建候选记忆。
- [x] 合法类型、用户证据明确、来源完整、无冲突、无重复、非敏感、策略允许且置信度至少为 `0.90` 的候选自动发布为正式记忆。
- [x] 自动晋升保留来源引用、操作审计、平台修改事务和独立 Git 提交。
- [x] 用户自然语言中的明确陈述或选择可以作为证据，不要求出现固定的“记住”“确认”或“决定”等关键词。
- [x] 用户提问、猜测、含糊提案和助手单独声称的事实不能自动晋升。
- [x] 低置信度、证据或来源不完整、冲突、可能重复、敏感、高影响、策略禁止或模型异常的内容进入待审核候选。
- [x] 候选审核界面默认突出显示需要人工处理的异常候选，不把正常自动晋升误导为待审核任务。
- [x] 自动晋升、无候选、待审核和被阻止场景均有服务级测试，并保留现有敏感过滤、冲突治理、真正遗忘和原子历史行为。
- [x] 中文 README 和管理台文案明确说明自动晋升是默认路径，人工审核是例外路径。
