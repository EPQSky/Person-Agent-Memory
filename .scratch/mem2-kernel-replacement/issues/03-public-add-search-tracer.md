# 03 — 公开 add/search tracer bullet

**What to build:** 打开新内核后，守护进程装配 mem2.0 Runtime，并通过 REST 和 MCP 提供写入和检索。用户写入一条记忆后可以按关键词和语义检索到它；重启后结果仍在；健康接口报告内核状态。

**Blocked by:** 02 — 存储适配器扩展

**Status:** done

- [x] 使用全新状态目录可以启动守护进程。
- [x] REST 写入接口可以创建记忆单元并返回标识。
- [x] REST 检索接口可以按关键词和向量召回该记忆。
- [x] MCP 检索和健康接口使用新内核。
- [x] 检索结果受 10K token 预算限制，并报告降级状态。
