# 05 — Codex 采集、会话 fallback 和演进

**What to build:** Codex Hook 把用户消息和助手最终回复写入正确的记忆区域。项目会话写入项目区域，绑定专题的学习会话写入专题区域，非项目会话写入会话区域。`evolve` 负责巩固和晋升。会话记忆按保留策略清理，采集保持 fail-open。

**Blocked by:** 04 — 记忆区域注册和绑定

**Status:** done

- [x] 绑定专题的学习会话采集写入专题记忆区域。
- [x] 无项目、无专题的会话采集写入会话记忆区域，并用会话标识隔离。
