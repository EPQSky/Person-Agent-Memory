# 01 — Prefactor：内核端口和特性开关

**What to build:** 产品外壳通过一个记忆内核端口访问记忆操作。旧记忆实现仍是默认路径；新内核由特性开关选择。关闭开关时，现有行为不变。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 产品外壳通过一个记忆内核端口执行健康检查、写入、检索、检视、更新、删除、审计、演进和区域解析。
- [ ] 关闭新内核特性开关时，现有记忆行为保持默认，用户可见行为不变。
- [ ] 特性开关在启动时可选择内核实现，并在健康或状态接口中可见。
- [ ] 端口契约测试覆盖假内核和现有实现。
- [ ] 特性开关关闭时，现有测试全部通过。
- [ ] 本 Ticket 不改变候选、检索或记忆写入的用户可见行为。
