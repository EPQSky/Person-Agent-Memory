# 08 — 自动晋升管线：显式和高置信度

**What to build:** 后台晋升任务从会话、项目和专题记忆中选出候选内容，分类到用户记忆、专题记忆、保留原区域、冲突或敏感，并把明确陈述且高置信度的内容晋升到目标区域。晋升单元保留来源引用和审计记录，重复运行不产生重复单元。

**Blocked by:** 05 — Codex 采集、会话 fallback 和演进；06 — 检视、更正、审计和导出
