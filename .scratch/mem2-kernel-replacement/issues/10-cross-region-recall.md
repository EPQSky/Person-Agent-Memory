# 10 — 跨区域召回

**What to build:** 用户可以显式选择用户记忆和若干专题或项目记忆区域，执行跨区域召回。结果按来源区域分组并带引用，受预算上限约束。项目会话默认不执行跨区域召回；全局召回必须由 MCP、命令行或 Agent 显式发起。

**Blocked by:** 04 — 记忆区域注册和绑定；05 — Codex 采集、会话 fallback 和演进；07 — 图投影和图扩展；09 — 自动晋升硬化

**Status:** ready-for-agent

- [ ] 跨区域召回必须显式开启，并至少选择一个区域。
- [ ] 只查询选中的用户、专题和项目区域；未选中的区域不进入结果。
- [ ] 结果按来源区域分组，并保留来源引用。
- [ ] 默认预算：总量 10K tokens；用户记忆最多 30%；每个选中专题或项目最多 20%；图扩展最多 20%；来源和结构最多 10%；预算可配置。
- [ ] 图扩展结果可以进入跨区域召回，并保留来源。
- [ ] 不同区域给出冲突事实时，结果保留多个来源，不静默合并。
- [ ] MCP、命令行或 Agent 可以显式发起跨区域召回。
- [ ] 测试覆盖区域选择、隔离、来源分组、预算、冲突、图扩展和故障降级。
- [ ] Spike gate：验证 mem2.0 的跨空间检索、来源标记和预算裁剪后再完成本 Ticket。
