# 07 — 图投影和图扩展

**What to build:** 记忆内核可以建立记忆单元之间的图关系，并在检索时返回一跳图扩展结果。图节点对应真实记忆单元，结果保留来源引用。图不可用时检索降级为直接命中。

**Blocked by:** 05 — Codex 采集、会话 fallback 和演进

**Status:** done

- [x] 图节点和边存储在 Milvus Lite collection 中，并按记忆区域隔离。
- [x] `evolve(ASSOCIATE)` 根据记忆单元建立图节点和关系边。
- [x] 图检索默认扩展一跳，并返回相关记忆单元。
- [x] 图扩展结果保留来源引用和区域信息。
- [x] 图故障时检索降级为直接命中，并报告通道错误。
- [x] 图数据在重启后保留，并支持重建。
- [x] 图节点和边 CRUD、BFS、scope 隔离、删除级联和关闭释放有契约测试。
- [x] 管理台或健康接口可以显示图状态。
