# 09 — 自动晋升硬化：多来源、冲突、敏感

**What to build:** 晋升管线只有在证据充分时才晋升。多个独立来源支持的内容可以晋升；证据不足、来源冲突或内容敏感时保留原区域并记录审计。用户始终可以更正、降权或遗忘晋升单元。

**Blocked by:** 08 — 自动晋升管线：显式和高置信度

**Status:** done

- [x] 晋升要求明确陈述且高置信度，或至少两个独立来源重复出现。
- [x] 证据不足的内容保留在来源区域，不晋升。
- [x] 多个来源事实冲突时跳过晋升，并记录冲突审计。
- [x] 敏感内容不会被自动晋升。
- [x] 用户可以更正、降权或遗忘晋升单元；源单元保留。
- [x] 重复晋升运行保持幂等。
- [x] 测试覆盖证据阈值、多来源、冲突、敏感、撤销和幂等。
