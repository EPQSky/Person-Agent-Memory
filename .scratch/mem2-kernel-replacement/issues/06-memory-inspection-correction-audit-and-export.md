# 06 — 检视、更正、审计和导出

**What to build:** 用户可以在管理台按记忆区域查看记忆单元，检视旧版本和生命周期，使用版本化更新或原地覆盖修正内容，执行归档、遗忘、降权和彻底删除，查看审计和来源，恢复旧内容，并把记忆导出为 Markdown。

**Blocked by:** 04 — 记忆区域注册和绑定

**Status:** done

- [x] 管理台和接口可以按区域列出记忆单元，并显示内容、元数据、生命周期、版本和来源。
- [x] `SUPERSEDE` 更新创建新版本，旧版本标记为 superseded。
- [x] `OVERWRITE` 更新原地修改，旧内容只保留在审计中。
- [x] `FORGET`、`ARCHIVE`、`DOWNWEIGHT` 和 `PURGE` 删除语义可用。
- [x] 审计和来源追溯可以查询，并且重启后仍可查询。
- [x] 恢复旧内容通过新的版本完成，不重写历史。
- [x] Markdown 导出是只读视图，不提供导入，也不构成第二套真源。
- [x] 测试覆盖列表、检视、两种更新、四种删除、审计、来源、恢复、导出和重启持久化。
