# 04 — 记忆区域注册和绑定

**What to build:** 用户可以创建用户、专题、项目和会话记忆区域，在管理台看到区域树，并把项目根目录绑定到项目记忆区域。默认只检索当前区域；显式选择区域时可以发起跨空间检索的底层请求。

**Blocked by:** 03 — 公开 add/search tracer bullet

**Status:** ready-for-agent

- [ ] 可以创建、列出和读取用户、专题、项目和会话四类记忆区域。
- [ ] 区域类型映射到 `user`、`topic:<id>`、`project:<id>` 和 `chat` 空间；会话区域使用会话级标识。
- [ ] 管理台显示记忆区域树：用户区域在上，专题和项目区域在下，当前会话作为临时节点。
- [ ] 项目根目录可以绑定到项目记忆区域。
- [ ] worktree 继承主项目绑定必须显式配置，不依赖目录名推断。
- [ ] 项目会话默认只检索当前项目空间。
- [ ] 显式跨空间请求只包含选中的区域，未选中的项目或专题不进入结果。
- [ ] 区域注册和绑定在重启后保留。
- [ ] 公开接口测试覆盖区域创建、绑定、默认隔离、显式跨空间选择和重启保留。
- [ ] 会话记忆的保留清理在 Ticket 05 交付。
