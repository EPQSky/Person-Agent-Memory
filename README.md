# Personal Agent Memory

面向个人编码智能体的本地优先记忆平台。它把跨会话的稳定事实、项目知识和专题知识保存为
可检索、可治理、可审计的长期记忆。它通过 Codex Hook、MCP（Model Context Protocol）和
本机管理台提供采集、检索和治理能力。

Personal Agent Memory 只服务单个本地用户和本机 Codex 会话。服务只监听回环地址，不使用
Docker，不需要系统级服务，也不提供远程同步。

## 产品定位

编码智能体在每次会话中重复学习相同的项目约束、个人偏好和领域知识。Personal Agent
Memory 把这些内容从会话上下文中分离出来，形成独立的记忆层：

- 跨会话保留稳定事实、偏好和可复用经验。
- 按用户、专题、项目和会话隔离记忆。
- 用来源、版本和审计记录支持检查与更正。
- 在模型服务不可用时仍能使用全文召回。
- 只向智能体提供有界、带来源的记忆上下文。

## 核心能力

- **本地优先**：记忆、索引、审计和 API 密钥保存在本机；服务只监听 `127.0.0.1`。
- **四个记忆区域**：用户、专题、项目和会话记忆，默认召回范围清晰。
- **显式项目绑定**：项目根目录与项目记忆区域建立显式关联；工作树继承也需要显式绑定。
- **多通道检索**：BM25 全文召回（Jieba 分析器）、稠密向量召回和图扩展；按 10,000 token
  预算返回记忆上下文包。
- **渐进式降级**：嵌入或图服务不可用时，检索继续返回可用的直接命中，并报告降级原因。
- **自动晋升与审计**：自动晋升支持多个目标；稳定个人事实和可泛化知识可按证据晋升；
  晋升、更新、删除和恢复留下版本与审计记录。
- **Codex 集成**：Hook 采集明确允许的会话内容；MCP 只提供只读的 `memory_search` 和
  `memory_get`。
- **本机管理台**：查看区域、记忆、来源、版本和审计；执行检查、更新、删除和恢复。

## 工作方式

1. Codex Hook 捕获明确的用户提示词和助手最终回复。
2. 采集内容进入对应记忆区域。项目会话写入项目记忆，专题会话写入专题记忆，其他会话
   写入会话记忆。
3. 记忆内核负责存储、索引、版本、生命周期和治理。`JiuwenMemory 0.2.0` 是唯一记忆
   内核。
4. 智能体通过 MCP 或 REST 检索记忆。检索结果包含来源引用，并受 token 预算限制。
5. 用户通过管理台检查、更正、归档、遗忘或恢复记忆。

## 记忆区域

| 区域 | 保存内容 | 默认召回 |
| --- | --- | --- |
| 用户记忆 | 跨项目的稳定事实和偏好 | 非项目、非专题会话；项目或专题会话需显式跨区域召回 |
| 专题记忆 | 技能、课程和领域知识 | 当前专题会话 |
| 项目记忆 | 具体项目的事实和约束 | 当前项目会话 |
| 会话记忆 | 非项目、非专题会话的临时内容 | 当前会话，默认保留 30 天 |

用户、专题和项目区域在存储层是同级空间。管理台把用户记忆显示为区域树根节点，但这不
表示其他区域继承用户区域的所有权或生命周期。

项目会话默认只召回当前项目记忆；专题会话默认只召回当前专题记忆；非项目、非专题会话
默认召回用户记忆和当前会话记忆。跨区域召回必须显式选择区域。

## 信任与治理

- 召回内容标记为不可信数据，不携带策略、工具授权或命令语义。
- MCP 只公开读取工具，不提供写入、审批或治理工具。
- 权威记忆修改通过管理台或受保护的后台接口执行，并留下版本和审计记录。
- 图节点必须对应有来源引用的记忆单元；没有有效来源的内容不进入记忆上下文包。
- Hook 不读取隐藏推理、原始工具输出、完整文件或召回的记忆内容。
- API 密钥和模型密钥保存在本机文件中，不写入记忆、图数据或审计事件。

## 存储与服务

长期记忆保存在平台状态目录的 `mem2/` 子目录：

- 记忆单元：SQLite。
- 稠密向量、全文索引和图节点边：本地 Milvus Lite 数据文件。
- 审计事件：SQLite。服务重启后，审计记录仍可查询。
- 版本标记：`mem2/VERSION`，内容为 `jiuwen-memory-0.2.0`。

一个用户级守护进程承载 Web、REST、MCP、会话采集和后台任务。服务默认监听
`http://127.0.0.1:7331`，通过 `systemd --user` 管理，不使用 `sudo`。

## 支持范围

已测试 Linux x86_64 上的 Ubuntu 22.04 和 Ubuntu 24.04。运行需要 Python 3.11-3.13、
`uv`、Node.js、Codex CLI、Git 和用户级 `systemd`。

当前版本只支持单用户、本机使用。以下能力不在范围内：

- 远程同步和多用户协作。
- 局域网或公网服务。
- Codex Cloud。
- 系统级服务和自动后台升级。
- Windows、macOS 和 ARM 平台。
